# How to update this profile

Everything on the profile page (README.md and every dark card in `assets/`) is generated by `scripts/generate.mjs`. **Edit the content block at the top of that file, not README.md** — the README is rewritten on every run.

Open `scripts/generate.mjs` on github.com, click the pencil, edit, commit. The GitHub Action redraws everything within a couple of minutes.

## What lives where (top of scripts/generate.mjs)
- `PROFILE` — name, the three lines next to the portrait, and the footer line
- `LINKS` — the buttons under the header (add LeetCode here: `{ id: "leetcode", label: "LEETCODE", href: "https://leetcode.com/u/your-name" }`)
- `ABOUT` — the about card, one string per paragraph
- `STACK` — the tech stack rows
- `PROJECTS` — one entry per project card, strongest first. Each card links to `repo`; the LIVE DEMO button links to `live`
- `EXPERIENCE` — one entry per internship or job

## Adding a project
Copy an existing entry in `PROJECTS`, give it a new `id` (letters and dashes), and fill in the fields. Keep to the 4–5 projects you can explain best, then pin the repo on your profile.

## Changing the portrait
The portrait is stored as ASCII text in `assets/portrait.txt`. To use a new photo, upload it as `assets/portrait.jpg` (square, head and shoulders, plain background works best) and delete `assets/portrait.txt`. The Action then converts the photo.

## If the stats stop updating
Actions tab → "profile graphics" → if GitHub disabled it, click **Enable workflow**, then **Run workflow**.
